# دليل قاعدة البيانات — إصدار 1.0

النسخة مضبوطة على MySQL بترميز utf8mb4 ومحرك InnoDB. ينشئ php artisan migrate --seed البنية والأدوار والصلاحيات دون حسابات أو أسعار أو طلبات. جميع ملفات Migrations الفعالة في database/migrations، والمخطط يتكون من 36 جدولًا شاملة جداول Laravel والصلاحيات.

| المجموعة | الجداول | الاستخدام |
|---|---|---|
| الحسابات | staff, users, stores, captain_profiles | هوية الإدارة والكابتن والتاجر والمتجر |
| الصلاحيات | roles, permissions, model_has_roles, model_has_permissions, role_has_permissions | Spatie بصلاحيات guard مستقل للموظفين |
| سجل الحسابات | account_audit_logs | التسجيل واعتماد وإيقاف الحسابات |
| التغطية | zones, pickup_addresses | مناطق العمل وعناوين استلام المتاجر |
| التسعير | tariffs, store_agreements | سعر كل اتجاه وأجور الكابتن والإعادة وخصم كل متجر |
| العروض | coupons, coupon_redemptions | الكوبونات وحجز الاستخدامات وربطها بالطلبات |
| الاشتراكات | delivery_packages, subscriptions | تعريف الباقة ونسخة شروطها عند طلب الاشتراك وتفعيلها |
| الهدايا | delivery_credits | الرصيد الأصلي والمتاح والصلاحية ومن منح الهدية |
| التوصيل | orders, order_events | بيانات الطلب ونسخة السعر والعنوان وسجل الحالات |
| المتابعة | order_issues | ملاحظات التاجر ورد فريق التشغيل |
| ذمم الطلبات | financial_entries | سجل واحد لكل تسليم نهائي أو إعادة نهائية، دون تكرار |
| التوريد | remittances | كشوف التحصيل من الكابتن وقرار استلامها |

العلاقات عبر مفاتيح أجنبية مع منع حذف الأصول المرتبطة بالسجلات. `owner_user_id` فريد؛ لكل حساب تاجر متجر واحد. المسار فريد بزوج منطقتي البداية والنهاية. `store_id` فريد في اتفاقيات المتاجر. مرجع إعادة إرسال الطلب فريد ضمن المتجر، والسجل المالي فريد لكل طلب. مبالغ الدفعات والسجل المالي بأعداد صحيحة؛ بعض صافي حساب المتجر قد يكون سالبًا لرسوم إعادة الطرد.

نسخة السعر داخل الطلب تمنع تعديل الطلبات القديمة عند تعديل تعريف تسعيرة أو اتفاق. تسوية المتجر لا تلمس سجل التحصيل من الكابتن؛ ولكل واحدة علاقة مستقلة بسجلات الطلبات المالية.

لتثبيت نظيف، أنشئ قاعدة MySQL فارغة ثم نفّذ php artisan migrate --seed. ويمكن استخدام ملف database/gaza_delivery.mysql.sql المرفق للاستيراد من phpMyAdmin في قاعدة فارغة بدل إنشاء الجداول بالمهاجرات؛ يتضمن جدول migrations لتتبع ما نُفّذ. لا تستورده فوق قاعدة بها بيانات. تفاصيل الطريقتين في MYSQL_SETUP_AR.md.

الحزمة المحلية `packages/delivery-foundation` تحتوي نماذج الهوية وخدماتها. ملف هجرة الهوية منشور في المجلد الرئيسي ويحافظ على اسمه القديم، وعُطّل تحميل نسخة الحزمة في هذا التطبيق حتى لا يكرر إنشاء الجداول.

## إضافات نسخة المتاجر 1.1

- neighborhoods: أحياء مرتبطة بالمناطق، فريدة بالمنطقة والاسم، تُدار من الإدارة.
- order_payments: تحويل إلكتروني واحد كامل لكل طلب، مع الوسيلة والمبلغ والحساب والمرجع وصاحب الحساب المستلم وحالة تحقق المالية وسجل المراجعة. المرجع فريد لكل وسيلة وحساب؛ لا تدعم النسخة تجزئة دفعة واحدة على عدة طلبات.
- orders: delivery_mode وscheduled_for بالتوقيت UTC، وto_neighborhood_id، ولقطة طريقة أجرة الكابتن ونسبته.
- tariffs: captain_pay_mode (fixed أو percent) وcaptain_share_bps. النسبة من الأجرة بعد الخصم، مع التقريب لأقرب أغورة.
- financial_entries: collected_minor مبالغ مستلمة لدى الكابتن وقابلة للتوريد بعد التحقق، وmerchant_received_minor مبالغ وصلت مباشرة للتاجر ولا تدخل توريد الكابتن. صافي التسوية = المبلغ لدى الكابتن − أجرة التوصيل.
- تحويل الجوالات القديمة المحلية من +970 أو +972 إلى 05 يتم عبر migration منفصل بعد فحص التعارضات؛ لا يُدمج حسابان تلقائيًا.
