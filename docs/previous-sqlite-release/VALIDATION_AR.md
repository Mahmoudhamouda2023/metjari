# تحقق إصدار التشغيل الأساسي 1.0 — 24 أكتوبر 2026

- Laravel 12.70.1، PHP 8.3، Yajra Oracle 12.7.2، Spatie Permission 6.25.0.
- 62 اختبارًا آليًا ناجحًا و333 assertion، مع قاعدة منفصلة في الذاكرة. تغطي الحسابات والصلاحيات واعتماد المتاجر وتغيير كلمات المرور، وعزل المتاجر والكباتن، وتسعير 12%، طرف تحمل الأجرة، نسخ السعر، صلاحية العروض وحدود الكوبون، حجز واستعادة الهدايا والباقات، إعادة الإرسال، دورة التحصيل والذمم، التوريد والتسوية والصرف، رفض التحصيل الناقص، ومنع إعادة استخدام نموذج تسوية قديم لمجموعة طلبات جديدة مساوية المبلغ، والتقارير والمصروفات وCSV وملاحظات الدعم واستعادة كلمات المرور.
- تجربة متصفح فعلية من إنشاء المناطق والتسعير واتفاق متجر 12% وعنوان الاستلام، إلى مراجعة طلب بقيمة بضاعة 100، وأجرة نهائية 8.80، وإسناده واستلامه وتسليمه، ثم توريد 100 كاملة، وتسوية التاجر 91.20، وصرف الكابتن 6.00 بشكل مستقل.
- طلب باقة من التاجر وتفعيلها بعد مرجع استلام، ومنح هدية، والبحث عبر Yajra Server-side من المتصفح.
- تحقق HTTP فعلي من رفض الكابتن عن مالية الإدارة (403) ورفض POST دون CSRF (419).
- الواجهات التي فُحصت على عرض 360 و1366 بكسل لا تتجاوز عرض الشاشة. الجداول العريضة قابلة للتمرير داخل بطاقاتها. لا أخطاء JavaScript ولا طلبات إلى نطاقات خارجية.
- CSS الرئيسي 5505 بايت بعد gzip في هذا البناء. الصفحات التشغيلية تعمل دون JavaScript. ملفات DataTables تُحمّل فقط على جدول المتاجر الإداري؛ الأحجام الدقيقة في asset-sizes.json. الحجم المنقول الفعلي يعتمد على تفعيل ضغط HTTP في الاستضافة.
- Composer validate --strict نجح، وComposer audit --no-dev لم يعرض تحذيرات معروفة وقت الفحص. تنسيق Pint وفحص بناء كاش config وroutes وviews ناجح.
- قاعدة التسليم: 34 جدولًا، أربعة أدوار وصلاحياتها، لا حسابات أو متاجر أو طلبات أو أسعار. SQLite integrity_check = ok، وforeign_key_check دون مخالفات.

الاختبارات ليست بديلًا عن تجربة قبول فريق التشغيل على استضافتكم وأسعاركم. لم يُنفّذ اختبار حمل إنتاجي أو اختبار MySQL فعلي أو تحويل أموال حقيقي أو تكامل رسائل/بنك. الكشوف تسجل التحويل اليدوي وتُراجع وفق المرجع المدخل.

- تثبيت فعلي من الأرشيف باستخدام composer install --no-dev ناجح. تحديث نسخة Phase 2 نجح مع بقاء بيانات staff/users/stores وملف .env ومفتاح التطبيق دون تغيير. أمر النسخ الاحتياطي أُجري فعليًا ونسخته اجتازت فحص سلامة SQLite.

تفاصيل قابلة للمراجعة: phpunit-results.xml، browser-results.json، asset-sizes.json، وrelease-checks.json. لا تتضمن الحزمة صور الاختبار أو قواعد بياناته أو بيانات الدخول التجريبية.
